# Руководство по разработке и обслуживанию Imagus Reborn MD

Этот документ предназначен для разработчиков, занимающихся поддержкой и развитием расширения.

## 1. Обслуживание правил (Sieve)

### Автоматическое обновление:
*   `chrome.alarms` срабатывает каждый час, но фактическое обновление происходит раз в 7 дней (проверяется через `sieveUpdateNext`).
*   Источник: `sieveRepository` из `defaults.json`.

### Алгоритм слияния (Merge Logic):
*   Правила, начинающиеся с символа `_`, считаются **пользовательскими/локальными**.
*   При обновлении они **никогда не перезаписываются**, а объединяются с новыми правилами из репозитория.

### Валидация при загрузке:
*   Проверяется структура JSON.
*   Должна быть хотя бы одна валидная запись с полями `link` или `img`.

## 2. Критические баги и Технический долг

### 1. Ошибка `persistState()` и сбой прерывания (Cancel All)
*   **Где**: `src-mv3-overlay/background/service.js`, `src-mv3-overlay/content/content.js`.
*   **Симптом**: При попытке остановить сканирование расширение падало, а загрузки продолжались.
*   **Решение (Optimal Solution)**:
    1.  **Background**: Удален `persistState()`. Добавлен протокол **Clean Stop**: пометка всех задач `canceled`, отмена активных `chrome.downloads` и `fetch`.
    2.  **Content**: Обнуление `PVI.downloadAllQueue` и визуальное подтверждение отмены в баннере.
*   **Статус**: ИСПРАВЛЕНО И ПРОТЕСТИРОВАНО в Chrome (MV3).

### 2. Персистентность очередей и состояние Service Worker
*   **Текущее состояние**: Используется хак `keepAlive` (интервал 25с в `service.js`), который успешно предотвращает засыпание Service Worker. Эмпирические тесты подтверждают стабильность работы при длительном простое.
*   **Решение**: Полное сохранение очередей в `chrome.storage.local` на текущем этапе признано **избыточным**. Приоритет смещен на корректную работу механизмов остановки и отмены. 
*   **Будущее улучшение**: Рассмотреть "ленивое" сохранение только статистики (`downloadStats`) для визуальной целостности при перезапуске расширения.

### 3. Очистка памяти (Memory Leaks)
*   Используется `Map` `activeControllers` для отслеживания Fetch-запросов.
*   **Важно**: При остановке или завершении фильтрации вызывайте `activeControllers.forEach(ctrl => ctrl.abort())`, чтобы не оставлять висящие запросы.

## 3. Советы по отладке

### Проверка фонового воркера:
*   Откройте `chrome://extensions`.
*   Найдите Imagus Reborn MD и нажмите на ссылку "Service Worker".
*   Все логи `console.log` из `service.js` будут видны только там.

### Проверка контентных скриптов:
*   Используйте консоль разработчика (`F12`) на любой странице.
*   Все логи `PVI.downloadAll` и процесса сканирования будут в консоли вкладки.

### Проверка страницы прогресса:
*   Если данные не обновляются, проверьте сообщения в консоли страницы прогресса.
*   Ключевая точка: `chrome.runtime.onMessage.addListener` в `download-progress.js`.

## 4. Добавление новых горячих клавиш
1.  Добавьте ключ в `defaults.json` (секция `keys`).
2.  Добавьте обработчик в `content.js`, функция `onKeyDown`.
3.  Зарегистрируйте новое поле ввода в `options.html` / `options.js`.
