# archive/docs — завершённые снапшоты (2026-10-29)

Эта папка — полка для документов, описывающих **уже выполненную работу**. Каждый файл здесь —
снапшот одного усилия: порт конкретной upstream-версии, план фиксов конкретной партии багов,
анализ конкретного замера. Их содержимое не «неправильное» — оно **исполнено и закрыто**, а
актуальное состояние проекта описано в живых документах:

- `Docs/PLAN.md` — живой реестр задач (MAIN/RESEARCH);
- `knowledge.md` (корень) — база знаний с датированными записями;
- `Audit/AUDIT_STATUS_CURRENT.md` — сводный статус всех аудитов;
- `Docs/README.md` — индекс живой документации.

## Почему файлы перенесены, а не удалены

`Docs/PLAN.md` ссылается на эти снапшоты как на evidence (историю решений). Удаление сломало бы
цепочку доказательств. Перенос выводит их из поля зрения при поиске по `Docs/`, но оставляет
доступ по прямому пути.
